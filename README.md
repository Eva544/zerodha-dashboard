# Zerodha Clone – Dashboard

A React-based trading dashboard for a Zerodha-inspired stock trading platform. It enables users to view holdings and positions, visualize portfolio data, and place simulated buy and sell orders while communicating with a Node.js/Express backend.

## 🚀 Live Demo

* **Frontend:** https://zerodha-frontend-cn66.onrender.com
* **Dashboard:** https://zerodha-dashboard-b447.onrender.com
  
## 📂 Related Repositories

* **Frontend:** https://github.com/Eva544/zerodha-frontend
* **Backend:** https://github.com/Eva544/zerodha-backend

## ✨ Features

* Clean and intuitive dashboard interface
* View holdings and positions
* Place simulated buy and sell orders
* Dynamic data rendering from the backend
* REST API integration using Axios

## 🛠️ Tech Stack

* React.js
* JavaScript
* HTML5
* CSS3
* Axios
* Chart.js
* React Router
